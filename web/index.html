01

Core Capabilities

[ eBPF / XDP ]
Kernel-Level Telemetry

eBPF probes attach to kernel tracepoints for process execution, file access, and network connections. Events are captured with nanosecond precision before any user-space process can observe or suppress them. XDP hooks operate at line rate, making drop decisions before the kernel network stack is engaged.

[ FIREWALL ]
Agentic Firewall

Every AI agent tool call — MCP, REST, SQL, shell, file — passes through the firewall before execution. A six-dimension risk model scores each call. A sequence-aware policy engine evaluates entire session action chains, blocking exfiltration patterns that are invisible when inspecting individual calls.

[ XDP / L4 ]
L4 Network Control

Inspired by Cloudflare's Unimog architecture, every host is both a worker and a load balancer. Packet-level decisions — drop, redirect to honeypot, or pass — occur in under one microsecond via XDP, before any TCP/IP stack processing. Per-source token buckets prevent flood attacks from exhausting the ingest path.

[ OR / MDKP ]
Resource-Optimised Telemetry

A Multi-Dimensional 0-1 Knapsack solver selects which telemetry events to transmit every 500ms, maximising detection value under five simultaneous resource budgets: CPU, memory, disk I/O, network packets, and bandwidth. Low-relevance events are dropped first. High-severity events are never sacrificed.

[ GRAPH / GNN ]
Graph-Augmented Detection

A property graph (Neo4j / Memgraph) models the relationships between processes, files, network endpoints, users, and agent sessions. Cypher triggers fire sub-100ms on graph writes. A trained GAT-based GNN classifies subgraphs for novel attack variants. Cypher catches known TTPs; GNN catches structural mutations.

[ TRANSFORMER ]
Sequence Foundation Model

A decoder-only transformer pre-trained on structured eBPF event sequences — not raw log text — scores anomalies by prediction error. Temporal positional encoding encodes inter-event timing deltas explicitly. A cross-attention fusion layer combines sequence and graph embeddings into a unified risk score.

03

Detection Engines

Cypher Pattern Matching Graph

Event-driven triggers fire the instant a graph write completes a dangerous pattern — no polling. Subgraph isomorphism against a MITRE ATT&CK-parameterised pattern library. Deterministic, explainable, zero false negatives for known TTPs.

  • Web shell → reverse shell (T1059)
  • Lateral movement 3+ hosts (T1021)
  • Privilege escalation + network (T1548)
  • Secret exfiltration path (T1552)
  • DGA / DNS tunnelling (T1071)
GNN Inference ML

A GAT-based graph classifier trained on 93,000+ synthetic MITRE-labelled attack graphs catches structural variants no Cypher rule was written for. GNNExplainer and attention weights surface critical edges for analyst review. Triggered by Cypher matches — never on every event.

  • 7 attack classes + benign
  • Synthetic data bootstraps training
  • Analyst TP/FP feedback loop
  • Graph canary nodes: zero false positives
  • Adversarial training (PGD)
eBPF Event Probes Kernel

Six kernel tracepoints capture ground truth that user-space cannot tamper with. Structured ring buffers eliminate copies. The OR scheduler applies relevance scoring — severity, delta from baseline, recency, contextual flags — before any event reaches the network.

  • execve, openat, write, connect
  • accept, fork — full process lineage
  • XDP: drop floods at wire speed
  • CO-RE portability (kernel 5.4+)
  • Per-CPU perf fallback (5.4–5.7)
Sequence Transformer Foundation Model

Structured eBPF event fields are tokenised into typed semantic embeddings — not subword text — preserving privilege levels, timing deltas, IP class semantics, and path sensitivity. Anomaly score is the negative log-probability of the observed next event. No attack labels required for pre-training.

  • Temporal PE encodes inter-event delta
  • Cross-attention fusion: seq ↔ graph
  • Pre-train on 500M+ event sequences
  • 2-week environment fine-tuning
  • 7-stage E2E validation pipeline

OIL — Olopa Intent Language

OIL is a declarative, compiled security language that replaces four separate policy surfaces — event filtering, graph correlation, risk scoring, and response playbooks — with a single coherent grammar. The compiler routes each rule to the optimal runtime: EPL  .so (15ns), Tokio stream operator, Memgraph Cypher trigger, or OPA Rego.

EPL HotPath
~15ns / event
Temporal Stream
< 50ms / window
Graph Trigger
< 100ms / write
OPA Policy
< 5ms / call
webshell_spawn_detect.oil
set shells = ["bash", "sh", "zsh", "python3"]
set web_servers = ["nginx", "apache2", "gunicorn"]

rule "webshell_spawn_detect" {
  from endpoint.process
  match process.exec as p
  where
    p.name in shells
    and p.parent.name in web_servers
  score
    base 70
    +15 if p.elevated
    +10 if p.signed == false
  respond {
    if score >= 85 {
      alert critical "Web shell detected"
      isolate network p.host_id
      open_case "Possible webshell"
    }
  }
}
