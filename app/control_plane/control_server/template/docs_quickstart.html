Getting Started

Quickstart

Start the stack, compile an OIL rule pack to runtime IR with oilc, then run the olopa agent with token-authenticated ingest.

1

Start the stack

docker compose up --build
Tip: This starts olopa-ingest, control-plane, and supporting services from your docker-compose.yml.
2

Compile OIL rules to runtime IR

Use oilc with --mode runtime-ir to compile your .oil rule files into a runtime IR artifact the agent can load.

cargo run --manifest-path oilc/Cargo.toml -- \
  --source oilc/src/rules \
  --mode runtime-ir \
  --emit-runtime-ir /tmp/runtime-ir.json \
  --diagnostics-format json
Tip: Run --mode check first for fast validation without emitting output. Use --mode ast or --mode mir to inspect intermediate stages. See the OIL compiler reference for all modes.
3

Enable ingest API token auth

export INGEST_API_TOKENS="ops-global-token,agent-acme-token:acme"
Token format: supports global and tenant-scoped tokens. token — global  |  token:tenant — single tenant  |  token:tenant-a|tenant-b — multi-tenant  |  token:* — all tenants.
4

Run the agent against ingest

Set the runtime IR path, ingest endpoint, tenant, and auth token, then launch the agent against a network interface.

OLOPA_RUNTIME_IR=/tmp/runtime-ir.json \
OLOPA_INGEST_URL=http://ingest.olopa.io/api/v1/ingest/batches \
OLOPA_INGEST_TENANT_ID=acme \
OLOPA_INGEST_API_TOKEN=agent-acme-token \
cargo run --manifest-path agent/Cargo.toml -p olopa -- --iface lo
Tip: By default the agent expects runtime IR at /etc/olopa/runtime-ir.json if OLOPA_RUNTIME_IR is not set. Default active probes: fork,exec,file,net. Add --probe-events tc to enable block egress enforcement via TC firewall rules.
5

Verify ingest is receiving telemetry

# Check ingest stats (global token)
curl -sS -H "Authorization: Bearer ops-global-token" \
  http://127.0.0.1:8000/api/v1/ingest/stats

# View recent events for a tenant
curl -sS -H "Authorization: Bearer agent-acme-token" \
  "http://127.0.0.1:8000/api/v1/ingest/recent?tenant_id=acme&limit=20"

# Check agent runtime status
cargo run --manifest-path agent/Cargo.toml -p olopa -- status
