Quickstart

Run ingest + control plane, compile an OIL rule pack to runtime IR, then run an agent with token-authenticated ingest.

1. Start the stack

docker compose up --build

This starts olopa-ingest, control-plane, and supporting services from your docker-compose.yml.

2. Compile OIL to runtime IR

cargo run --manifest-path oilc/Cargo.toml -- \
  --source oilc/src/rules \
  --mode runtime-ir \
  --emit-runtime-ir /tmp/runtime-ir.json \
  --diagnostics-format json

Use /tmp/runtime-ir.json for local testing, then distribute the artifact to agents.

3. Enable ingest API token auth

export INGEST_API_TOKENS="ops-global-token,agent-acme-token:acme"

Token format supports global and tenant-scoped tokens (token, token:tenant, token:tenant-a|tenant-b, token:*).

4. Run an agent against ingest

OLOPA_RUNTIME_IR=/tmp/runtime-ir.json \
OLOPA_INGEST_URL=http://127.0.0.1:8000/api/v1/ingest/batches \
OLOPA_INGEST_TENANT_ID=acme \
OLOPA_INGEST_API_TOKEN=agent-acme-token \
cargo run --manifest-path agent/Cargo.toml -p olopa -- --iface lo

By default the agent expects runtime IR at /etc/olopa/runtime-ir.json if OLOPA_RUNTIME_IR is not set.

5. Verify ingest is receiving telemetry

curl -sS -H "Authorization: Bearer ops-global-token" \
  http://127.0.0.1:8000/api/v1/ingest/stats

curl -sS -H "Authorization: Bearer agent-acme-token" \
  "http://127.0.0.1:8000/api/v1/ingest/recent?tenant_id=acme&limit=20"

Next: configure runtime, paths, probe options, and auth headers in Agent Configuration.
