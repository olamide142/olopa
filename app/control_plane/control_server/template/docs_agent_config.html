Agent Configuration

Runtime IR, ingest endpoint, tenant identity, and auth configuration for the olopa agent.

Defaults

Setting Default Purpose
OLOPA_RUNTIME_IR /etc/olopa/runtime-ir.json Path to compiler-emitted runtime IR artifact loaded at startup.
OLOPA_INGEST_URL http://127.0.0.1:8000/api/v1/ingest/batches HTTP endpoint used for ingest batch POSTs.
OLOPA_INGEST_TENANT_ID default Tenant id included in outgoing ingest payloads.
OLOPA_INGEST_HOST_ID agent-local (or host name) Host identity included in ingest payloads.
OLOPA_STATUS_PATH /tmp/olopa/agent/status.json Location of runtime status snapshot used by olopa status.

Auth options

Env / Flag Header sent to ingest Notes
OLOPA_INGEST_API_TOKEN / --ingest-api-token Authorization: Bearer <token> Preferred option when ingest is configured with API tokens.
OLOPA_INGEST_API_KEY / --ingest-api-key x-api-key: <key> Alternative auth header supported by ingest server.

Recommended environment block

export OLOPA_RUNTIME_IR=/etc/olopa/runtime-ir.json
export OLOPA_INGEST_URL=http://127.0.0.1:8000/api/v1/ingest/batches
export OLOPA_INGEST_TENANT_ID=acme
export OLOPA_INGEST_HOST_ID=host-01
export OLOPA_INGEST_API_TOKEN=agent-acme-token
export OLOPA_STATUS_PATH=/tmp/olopa/agent/status.json

CLI override example

cargo run --manifest-path agent/Cargo.toml -p olopa -- \
  --iface eth0 \
  --runtime-ir /etc/olopa/runtime-ir.json \
  --ingest-url http://127.0.0.1:8000/api/v1/ingest/batches \
  --ingest-tenant-id acme \
  --ingest-host-id host-01 \
  --ingest-api-token agent-acme-token

Fallback behavior

If runtime IR fails to load, agent startup fails by default. Set OLOPA_ALLOW_SIMPLE_RULE_FALLBACK=1 (or --allow-simple-rule-fallback) only for temporary recovery scenarios.
